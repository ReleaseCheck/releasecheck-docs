# Contributing to the documentation

This repository contains user-facing documentation only. The implementation, architecture decisions, security policy, and roadmap live in the [core repository](https://github.com/ReleaseCheck/releasecheck). GitHub Actions integration lives in the [Action repository](https://github.com/ReleaseCheck/releasecheck-action).

Before opening a change:

1. Read the core `PROJECT_CONTEXT.md`, `ROADMAP.md`, `README.md`, and `docs/DESIGN.md`.
2. Keep examples aligned with the released or explicitly documented CLI behavior.
3. Do not claim guarantees, adoption, compatibility, or release status that the core repository does not establish.
4. Check links and code examples locally.

Documentation changes should explain what is known, what is inferred, and what remains undetermined. Avoid marketing language and avoid copying competitor documentation.
